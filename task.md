# Задача
Программа, загружает текст древнеисландских саг на разных языках и достает из него упоминания числительных в различных словоформах. Каждое найденное числительное вместе с контекстом выводится в csv и печатается в консоль.

# Поддерживаемые языки

- русский
- английский
- древнеисландский

# Формат ввода

Один или несколько xml файлов для анализа. Задается маской, например: ./data/*.en.xml
Языковой модуль берется выбирается из расширения


# Формат вывода
Формат CSV, delimiter - ";", with header
Колонки:
- number_word - число в той форме как встречается ('')
- number - число, записанное цифрами
- context - цитата, 3 предложения (до, вхождение, после)
- chapter - номер главы
- saga - имя входного файла без расширения
- lang - использованный язык

# Источники данных

SagasDB github repo https://github.com/sveinbjornt/sagadb.org/tree/master/src
XML файлы должны быть скачаны и размещены в папке ./data/ не изменяя их структуру

# Технические требования

Python 3.12

Makefile c командами:
- make setup (создание venv и установка зависимостей)
- make run (запуск для всех файлов из ./data/)
- make test (запуск юнитестов)

Нефункциональные требования
- Языковые модули унифицированы и лежат в разных файлах.
- Есть юнит тесты: на структуру входного xml файла, на каждый языковой модуль. 
- Юниттесты пишутся по общей схеме: setup - формирование xml, act, assert(проверка ожидаемого выхода). Похожие тесты организуются через параметризованные тесты.
