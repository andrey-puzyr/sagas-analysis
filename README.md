# Sagas Analysis

Программа для извлечения числительных из древнеисландских саг.

## Возможности

- Загрузка текстов саг из XML файлов (формат SagasDB)
- Поиск числительных (0-100) в различных словоформах
- Извлечение контекста (3 предложения) для каждого вхождения
- Вывод результатов в CSV формате

## Поддерживаемые языки

| Расширение | Язык |
|------------|------|
| `.en.xml` | Английский |
| `.on.xml` | Древнеисландский (Old Norse) |

## Установка

```bash
make setup
```

## Использование

```bash
# Запуск для всех поддерживаемых файлов
make run

# Запуск для конкретных файлов
.venv/bin/python -m src.main "./data/*.en.xml"
```

## Тестирование

```bash
make test
```

## Формат вывода

CSV с разделителем `;`:

| Колонка | Описание |
|---------|----------|
| number_word | Числительное как в тексте |
| number | Число цифрами |
| context | 3 предложения контекста |
| chapter | Номер главы |
| saga | Имя файла без расширения |
| lang | Код языка |

## Структура проекта

```
src/
├── main.py              # Точка входа, CLI
├── xml_parser.py        # Парсинг XML файлов саг
├── context_extractor.py # Извлечение контекста предложений
└── languages/
    ├── base.py          # Базовый класс языкового модуля
    ├── english.py       # Английские числительные
    └── old_norse.py     # Древнеисландские числительные
```

## Источник данных

XML файлы из [SagasDB](https://github.com/sveinbjornt/sagadb.org/tree/master/src).
